# Саундтрек GTA VI: ПР7, тестування та аудит якості

Неофіційна навчальна SPA на чистому JavaScript, без бібліотек і фреймворків. Не пов'язана з Rockstar Games; усі назви та музика належать правовласникам.
Треки (назви, виконавці) взято зі сторінки https://www.rockstargames.com/VI/music. Аудіо на сторінці не відтворюється: кнопки «Слухати» відкривають офіційні сторінки прослуховування (`lnk.to`) у новій вкладці.

## Структура

| Файл | Призначення |
|---|---|
| `index.html` | розмітка, `<meta name="description">`, підключення `tracks.js`, `app.js`, `tests.js` з `defer` |
| `style.css` | стилі та CSS-змінні палітри |
| `tracks.js` | дані: 58 треків (34 стандартне видання, 23 делюкс, 1 сингл саундтреку) |
| `app.js` | чисті функції (`validateInput`, `validateEmail`, `isValidState`, `isValidRoute`, `isSafeUrl`, `filterTracks`, `truncate`) та логіка інтерфейсу |
| `tests.js` | `runUnitTests()`: 34 перевірки через `console.assert`, виклик під час завантаження |

## 2. Адаптивність

Перевірено всі розділи та всі чотири стани «Медіатеки» на ширинах 320, 375, 414, 768, 1024 і 1440 px: горизонтальної прокрутки немає, текстові блоки не накладаються. Табличний треклист має власну горизонтальну прокрутку всередині контейнера на вузьких екранах.

## 4. Модульні перевірки

`tests.js` перевіряє чисті функції з `app.js`, які не звертаються до DOM:
валідний текст, порожній рядок, рядок із пробілів, `null` і число, межу довжини, коректну і некоректну пошту, допустимі й недопустимі стани та маршрути, безпечні й небезпечні адреси (`javascript:`, `http:`, чужий і схожий домен), пошук за назвою та виконавцем, HTML у запиті як текст, скорочення довгого рядка, а також що всі 58 треків мають безпечні посилання.

Результат у консолі при завантаженні: `Модульні перевірки: 34 з 34 пройдено`, без `Assertion failed`. Тестовий код не торкається DOM і `localStorage`.
